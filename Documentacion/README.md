# 📚 Documentación del Proyecto

Esta carpeta es el cerebro del juego. Aquí guardamos todas las reglas, la historia y la planificación.

* **Game Design Document (GDD):** Documentos detallando cómo funcionan las mecánicas, la inteligencia de los enemigos y el flujo de los niveles.
* **Guión y Narrativa:** Diálogos, descripción de los personajes y estructura de la historia.
* **Artefactos de Gestión:** Cronogramas, actas de reuniones o listas de tareas a gran escala.

**Consejo de formato:** Prioricen el uso de archivos de texto simple, Markdown (`.md`) o PDFs ligeros. Si utilizan plataformas externas (como Google Docs, Miro o Trello), dejen aquí un archivo con los enlaces directos de acceso para el equipo.
